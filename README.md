# Backend Interview Study

Comprehensive study materials for PHP Backend Developer / Backend Engineer interviews.

## Contents

```
├── ROADMAP.md                 ← 6-week study plan
├── feedback1.md               ← Interview feedback (Backend Engineer)
├── feedback2.md               ← Interview feedback (PHP Backend Dev)
└── docs/
    ├── 01-php-internals.md    ← PHP-FPM, strict/loose, references, error handling
    ├── 02-laravel.md          ← Policies vs Gates, middleware, Eloquent, queues
    ├── 03-database-design.md  ← Normalization, NULL, constraints, upserts, transactions
    ├── 04-api-design.md       ← REST, versioning, idempotency, rate limiting, JWT
    ├── 05-scalability.md      ← Connection pooling, caching, queues, horizontal scaling
    ├── 06-devops.md           ← Docker, CI/CD, monitoring, health checks
    ├── 07-mock-interview.md   ← 10 topics to practice explaining out loud
```

## Quick Start

1. Read `ROADMAP.md` for the full study plan
2. Start with `docs/07-mock-interview.md` to practice verbal answers
3. Read corresponding docs for deeper understanding
4. Build the mini project in `docs/08-additional-study.md`
5. Practice coding challenges on LeetCode/Codewars

## Key Topics from Interview Feedback

### Strengths
- PHP fundamentals (strict/loose, pass-by-reference)
- Scalable architecture thinking
- Idempotency and transaction concepts
- Laravel practical exposure

### Areas to Improve
- Laravel Policies vs Gates precision
- PHP-FPM lifecycle and connection management
- Database normalization (NULL behavior, functional dependencies)
- API architecture details (connection pooling, retry-safe storage)
- Coding challenge — address all requirements and edge cases
